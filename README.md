# React Todo App 📝

A responsive Todo List application built using React and Tailwind CSS. The application allows users to manage daily tasks, track completion status, and save their todos locally using browser LocalStorage.

## ✨ Features

- Add new todos.
- Edit existing todos.
- Delete individual todos.
- Mark todos as completed using checkboxes.
- Show or hide completed tasks.
- Automatically save todos using LocalStorage.
- Unique task IDs using UUID.
- Responsive user interface.
- Interactive buttons with hover effects.

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Icons
- UUID
- HTML5
- Vite
- LocalStorage

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd react-todo-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
